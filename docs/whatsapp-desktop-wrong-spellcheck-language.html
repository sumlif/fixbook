WhatsAppNOTE / 001

WhatsApp underlines correct words? Fix the spell-check language.

Salih · 08 November 2026 · 6 min read

✓ Confirmed in one real troubleshooting session · Turkish tested

Your keyboard is set correctly. The language pack is installed. Yet WhatsApp underlines almost every word in your language and suggests English replacements.

The fix that worked

Start WhatsApp’s WebView2 component with the desired language using an app-specific registry override. In our test, --lang=tr-TR enabled Turkish spell checking while Windows stayed in English.

Tested environment

  • Windows 11, English display language.
  • WhatsApp Desktop 2.3000.1053651158.264201.
  • Microsoft Edge WebView2 157.0.4341.42.
  • Writing language: Turkish. Confirmed on 8 November 2026.

This is a local workaround, not an official WhatsApp setting. Microsoft documents WebView2 flags as diagnostic/development options that may change or disappear. Other languages and versions need their own verification.

How to recognize this problem

Correct words such as merhaba and selam receive red underlines, while the context menu suggests English words. Changing the keyboard, Windows language order or the app’s interface language did not fix this case.

Apply the workaround

1. Check for an existing override

Open PowerShell under the Windows account that runs WhatsApp. Run:

reg query "HKCU\Software\Policies\Microsoft\Edge\WebView2\AdditionalBrowserArguments" /v WhatsApp.Root.exe

If Windows says the registry key or value cannot be found, continue. If it returns an existing value, save its exact contents before making changes. Do not replace existing arguments blindly; they may serve another purpose.

2. Set the writing language

For the tested Turkish case, run:

reg add "HKCU\Software\Policies\Microsoft\Edge\WebView2\AdditionalBrowserArguments" /v WhatsApp.Root.exe /t REG_SZ /d "--lang=tr-TR" /f

This creates one current-user value named WhatsApp.Root.exe. It does not change Windows’ display language. Use the language table below to understand other locale codes; those variants have not been confirmed in this case.

3. Fully close and reopen WhatsApp

Use Task Manager → Processes → WhatsApp → End task, then launch WhatsApp again. Closing its window may only minimize it to the system tray.

4. Check the result

With Settings → Chats → Spell check enabled, type correct words in your language followed by an intentionally invented word. Correct Turkish words stopped being underlined in our test, while the invented word remained marked.

Use a different language

The method is written around a language code, not around Turkish text. Replace tr-TR with the desired locale to test another language. A locale code alone does not guarantee that its dictionary is installed or supported.

Check the startup language

If the workaround does not take effect, inspect WhatsApp’s WebView2 processes:

Get-CimInstance Win32_Process |
Where-Object { $_.Name -eq 'msedgewebview2.exe' -and $_.CommandLine -match 'WhatsApp' } |
Select-Object -ExpandProperty CommandLine

Look for processes belonging to WhatsApp.Root.exe and the WhatsAppDesktop data folder. In the original case, renderer and utility processes had --lang=en-US. This is a useful clue about runtime language, not proof by itself of the dictionary being used.

Undo the change

If there was no previous value, remove only the value created above:

reg delete "HKCU\Software\Policies\Microsoft\Edge\WebView2\AdditionalBrowserArguments" /v WhatsApp.Root.exe /f

Fully close and reopen WhatsApp. If a value already existed before the test, restore its original contents instead of deleting it.

What did not work in this case

  • Reordering Windows’ preferred languages and restarting Windows.
  • Changing the keyboard or enabling multilingual text suggestions.
  • Changing WhatsApp’s interface language to Turkish.
  • Editing spellcheck and intl.selected_languages in the WebView2 Preferences file: WhatsApp rewrote the settings on startup.
