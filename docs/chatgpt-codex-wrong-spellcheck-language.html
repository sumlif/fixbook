Change the spell-check dictionary in ChatGPT / Codex Desktop.

✓ Confirmed in one real troubleshooting session · Turkish tested

If correct words in your language are underlined in ChatGPT / Codex Desktop, the app’s own dictionary list may contain only English—even when Windows has the right language installed.

The fix that worked

Back up the active Preferences file, fully quit the app, and add your writing language to its spellcheck section.

Tested case

Windows 11 with an English display language, using the combined ChatGPT / Codex desktop app. Turkish spell checking was confirmed on 8 November 2026. The exact app version was not recorded. This workaround may differ across app versions and installation types.

1. Find the active profile

Press Win + R and open:

%LOCALAPPDATA%\Packages

For the tested Microsoft Store installation, the file was under:

OpenAI.Codex_2p2nqsd0c76g0\LocalCache\Roaming\Codex\web\Codex\Default\Preferences

Some installations use the following location instead. Verify that it actually exists; paths vary.

%APPDATA%\Codex\web\Codex\Default\Preferences

Use the file named Preferences, not Secure Preferences. Do not edit login databases or delete the profile folder.

2. Back up, quit and edit

Copy Preferences to Preferences.backup. Fully quit the app, including any background process, before editing. Open the original file in a text editor and find spellcheck.

The original section in this case was:

"spellcheck":{"dictionaries":["en-US"],"dictionary":""}

Replace that section—not the entire file—with:

"spellcheck":{"dictionaries":["tr-TR","tr","en-US"],"dictionary":"tr-TR"}

Keep the surrounding JSON commas and braces intact. Save to the original Preferences filename without adding a .txt extension.

3. Reopen and verify

Launch the app and type correct words followed by an invented word. In our test, correct Turkish words no longer received red underlines, but the invented word still did. Windows remained in English.

Other languages

Use your language’s supported dictionary code rather than assuming Turkish codes apply. The table gives locale examples; only Turkish was tested here. Regional and base-language codes may behave differently.

Undo the edit

Fully quit the app. Preserve a copy of the current file, then restore Preferences.backup as Preferences. The backup restores all preferences as they were at backup time, so later preference changes may be lost.

If the file changes back

First verify the app was fully stopped. If it still rewrites your dictionary list, stop repeating the same edit. Another profile or an app-controlled startup setting may be involved. Updates may also reset the workaround. Do not make the entire file read-only.

WhatsApp behaved differently in our session: its Preferences edits did not persist. Use the separate WhatsApp workaround for that tested case.
